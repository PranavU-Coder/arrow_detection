# arrow_detection
for general CV-purposes &amp; simulations

dataset credits : https://www.kaggle.com/datasets/jithinnambiarj/directions?resource=download

utilizes yolo11m model for classifying left and right arrows in real time 

total samples :

train data : 2673
validation data : 402
test data : 136

stats :

on validation dataset : 94-96% recall with 95-98% precision

on test dataset : 96-99% recall with 95-96% precision

problems : false positives
